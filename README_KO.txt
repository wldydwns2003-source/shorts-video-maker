[쇼츠 영상 소스 메이커 - 실제 실행 버전]

1. Windows PC에 Python 3.11 이상을 설치합니다.
2. install.bat을 한 번 실행합니다.
3. start.bat을 실행합니다.
4. PC 브라우저에서 http://127.0.0.1:8000 을 엽니다.
5. 대본 입력 -> 유튜브 영상 찾기 -> 장면별 영상 선택 -> MP4 렌더링 순서로 사용합니다.

휴대폰 사용:
- PC와 휴대폰을 같은 Wi-Fi에 연결합니다.
- 명령 프롬프트에서 ipconfig로 PC의 IPv4 주소를 확인합니다.
- 휴대폰에서 http://PC주소:8000 으로 접속합니다. 예: http://192.168.0.10:8000
- Windows 방화벽이 뜨면 개인 네트워크 액세스를 허용합니다.

중요:
- 검색과 다운로드는 공개 YouTube 영상에 대해 동작합니다.
- YouTube의 변경, 연령 제한, 로그인 요구 영상은 실패할 수 있습니다.
- 영상 사용 권한과 저작권 확인 책임은 사용자에게 있습니다.
- 완성 파일은 work 폴더에도 저장됩니다.
